# Fabrika Malharia

Sistema web para gestão e acompanhamento da produção de uma fábrica de malharia.

## Sobre o projeto

O Fabrika Malharia permite organizar e acompanhar pedidos, tecidos e indicadores de produção por meio de uma interface administrativa.

## Funcionalidades

* 📊 Dashboard com indicadores
* 📦 Gerenciamento de pedidos
* 🧵 Cadastro e consulta de tecidos
* 🔎 Detalhamento de pedidos
* ⚙️ Configurações

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Git e GitHub

## 🎯 Objetivo

Desenvolver uma solução web para facilitar a organização e o acompanhamento dos processos de produção de uma fábrica de malharia.
